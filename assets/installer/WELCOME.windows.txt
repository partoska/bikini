Bikini (bikini)

This installer will place the bikini command-line tool and the libbikini
library with its headers on your Windows system, and can add bikini to
your PATH, so that it is available in Command Prompt and PowerShell.

Bikini is a small, minimal INI library and query tool. The bikini
command reads INI files and prints sections, keys and values, so that
shell scripts and pipelines can read and edit configuration without sed
or awk. The library, libbikini, reads and writes the same INI text from C.

After installation, run "bikini -h" in a terminal to get started.
