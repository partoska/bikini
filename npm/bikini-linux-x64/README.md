# @partoska/bikini-linux-x64

This is the **Linux x64** native binary for
[`@partoska/bikini`](https://www.npmjs.com/package/@partoska/bikini).

You should not install this package directly. Install the main package instead,
and npm will automatically pull in the correct binary for your platform:

```bash
npm install -g @partoska/bikini
```

See the [`@partoska/bikini` README](https://www.npmjs.com/package/@partoska/bikini)
for documentation and usage.
